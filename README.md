# jadeia.org

A small static site — personal chronicle and archive, dragon lore and heraldry. No build step, no framework.

## Stack

- Static HTML/CSS
- Fonts: Cinzel, IM Fell English, UnifrakturMaguntia (Google Fonts)
- Hosted on Netlify
- Analytics: GA4 (`G-61T0721KTX`)

## Structure

```
/index.html       home
/chronicles/      chronicle entries
/plates/          image gallery
/images/          sourced imagery — see attribution below
```
